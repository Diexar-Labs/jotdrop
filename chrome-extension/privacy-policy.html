JotDrop - Privacy Policy

Effective date: 2026-11-06  |  Publisher: DiexarLabs  |  License: MIT

JotDrop Web Clipper is a Chrome extension that saves the current browser tab as a JotDrop note. You choose where clips go: to the JotDrop plugin in Obsidian on your own computer, to your end-to-end encrypted JotDrop Cloud, or to both. This page explains exactly what the extension does and does not do with your data.

1. Data collected by us

None.

The extension has no analytics, no telemetry, no crash reporting and no advertising. In Obsidian mode it contacts no server at all. In JotDrop Cloud mode it sends your clips to your own JotDrop Cloud only in encrypted form, which we cannot read (see section 4), and it tells that server that it is the JotDrop Web Clipper and which version, so that you can see your devices and their versions in your cloud.

2. What the extension reads from your browser

When you open the extension, it reads:

  • The current tab's title and URL
  • Any text you have selected on the page (if any)

This information is read on demand only, not continuously and not in the background. Nothing is saved until you press Save.

3. What is stored on this device

JotDrop stores its settings in chrome.storage.local, which stays on this device and is never synced to your Google account:

  • Where clips go: Obsidian, JotDrop Cloud or both
  • For Obsidian (optional): the port number of the JotDrop plugin's clip server and the bearer token that authenticates requests to it
  • For JotDrop Cloud: the cloud keys of this browser (a device token and the key that encrypts your notes), sealed with an unlock passphrase you choose. The passphrase itself is never stored.
  • For JotDrop Cloud: encrypted clips that are waiting to be uploaded, for example after a lost connection. They are encrypted before they are stored.

If you tick "Stay unlocked until the browser closes", the unsealed cloud keys are kept in chrome.storage.session, which lives in memory only and is cleared when the browser closes or when you choose Lock now. "Disconnect this browser" in the settings removes the cloud keys and any waiting clips from this device.

4. Where your data goes

Obsidian mode. Your clip never leaves your computer. It travels over one of two local routes:

  • Background connection (optional): the title, URL, selected text, tags, color and pin are sent in a single HTTP request to http://127.0.0.1 (your own computer) on the port you configured, authenticated with the bearer token. The request is received by the JotDrop plugin running inside Obsidian on your computer.
  • Direct mode (default): the extension opens a local obsidian://jotdrop-clip link that is handled by the JotDrop plugin in Obsidian on your computer. The bearer token is never included in it.

JotDrop Cloud mode. The extension turns the clip into a Markdown note and encrypts it in your browser with your cloud key (AES-GCM) before it is sent. Only the encrypted note goes to https://app.jotdrop.net, the JotDrop Cloud you paired with, together with the device token that proves this browser is one of your devices. The server stores the encrypted note and technical data such as its size and time, but it cannot read the title, URL, selection or tags. Your cloud account and the cloud itself are covered by the JotDrop Cloud privacy policy at app.jotdrop.net/privacy.

Pairing uses a one-time code that you create yourself in the JotDrop web app. Connecting adds this browser as a device of your cloud, which is shown in the web app under Devices & recovery, where you can also sign it out.

5. Third parties

None.

JotDrop shares no data with any third party. There are no embedded SDKs, no tracking pixels and no external scripts. All code runs from the extension package.

6. Permissions used

The extension requests only the permissions it needs:

  • activeTab - to read the title and URL of the current tab, only after you open the extension
  • scripting - for a one-time read of the text you selected on the active tab when you open the extension
  • storage - to keep the settings, sealed cloud keys and waiting encrypted clips described in section 3 on this device
  • localhost host permissions (http://127.0.0.1/*, http://localhost/*) - to send clips only to the JotDrop plugin running on this computer
  • optional access to https://app.jotdrop.net/* - requested only when you connect JotDrop Cloud, to pair with your cloud and upload encrypted clips. You can remove it at any time in Chrome's extension settings.
